# Advanced Sales Analytics — Microsoft Excel

This project showcases advanced sales analytics using Microsoft Excel to simulate a Business Analyst portfolio project. It covers:

## 📊 Key Analytics Performed
- **Descriptive Analytics:** Sales, profit, and margin summaries by category and time
- **Diagnostic Analytics:** Correlation analysis between discount, quantity, profit margin
- **Predictive Analytics:** Sales forecasting using `FORECAST.LINEAR`
- **Visuals & Charts:** Pivot charts, KPIs, trend charts

## 📂 Sheets Overview
- `Raw Data`: Transaction-level sales data
- `Descriptive Analysis`: High-level summaries and category trends
- `Diagnostic Analysis`: Correlations and segmentation
- `Predictive Analytics`: Forecasting sales for future months

## 📈 Tools Used
- Excel PivotTables & PivotCharts
- Formulas: `SUMIFS`, `FORECAST.LINEAR`, trendline logic
- Visualizations: Bar charts, time-series, KPI tables
